# 合作空间：可接续设计会话与一键启动

2026-10-23，依据本轮用户确认实施，属于 M8 合作空间体验增量。

## 用户流程

1. 从任务的固定「团队设计」入口打开专用会话，不借用任务初始开发会话。
2. 自然语言讨论、生成和修改成员及协作图；讨论与当前图同处一页。切走返回恢复历史、生成状态和未发送输入。
3. 图是可编辑团队配置，保留成员身份、原会话及手动位置；修改针对当前图，不生成无法接续的孤立文本。
4. 「确认并开始工作」一次保存团队、复用或创建成员会话，并交给既有合作 Goal 推进。依赖和分工继续由现有工作图及协调者处理，不无差别唤醒全体。
5. 可仅保存、稍后开始。关闭面板不停止运行；可显式停止。应用退出后的中断遵循原恢复行为，不自动重放。

## 实现边界

- 复用 Session / Run / Plan、save_team_draft、SpaceService 与 SpaceTeamService，不另建模型循环或工作流运行时。
- 专用会话与草稿归当前任务，保存于应用数据根；旧生成结果及旧空间保持可读。
- 原事件订阅显示真实运行状态；自然语言改图读取当前编辑配置，普通讨论不强制产出草稿。
- 创建或启动局部失败保留已完成事实和错误，重复操作不重复创建成员或重放 Goal；不新增信任、审批或逐成员确认。

## 图排布与编辑（2026-10-23 反馈修正）

- 模型负责成员、职责和关系语义；初次生成由本地排布处理坐标，按固定卡片边界和实际画布尺寸适配视口。恢复旧图修复卡片重叠，后续语义修改保留已有人工位置，新增节点避让；显式「自动排布」才重排整图。
- 双向／并行关系分开走线，自环沿卡片外侧绘制；选中成员突出关联线，并列出来源 → 目标。增加默认画布高度，并提供可收起的大图视图。
- 成员／关系使用固定侧面编辑区，关闭和删除在顶部，长内容独立滚动。新增关系先选择来源和目标，不默认生成自环；删除成员配置同时去掉其连线，保留历史会话。
- 一个项目包含多个任务，每个任务一份合作空间与一个专用设计会话。界面直接说明所属任务；模板跨任务复用，不在本次增加多空间运行时或版本系统。

## 定向验证

- 独立会话身份、连续讨论改同一张图、原开发会话不被写入。
- 页面切换及重启恢复、输入保存、运行状态和取消。
- 一键创建并启动、重复确认、成员复用、局部失败保留。
- 使用 tests/ 与 .artifacts/tests/；离线服务、真实 Electron 与真实模型证据分开记录。

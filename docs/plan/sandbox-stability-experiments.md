# Windows 沙箱稳定性与有效性实验

日期：2026-10-20。范围为 M6 首次实现后的定向补充，实际结果记录在 [M6 进度](../progress/m6.md)。

> 用户已纠正验收目标：**沙箱日常功能完全不提权**，包括命令、终端和本地网页预览。原“每次应用一次授权”路线已经放弃，不能把减少弹窗当作免提权交付。

## 目标与调整

通过真实 AppContainer 执行确认可用性、文件／网络边界及生命周期，不以进程启动成功替代隔离有效。本轮不修改 VPN、代理、UAC 策略或全局防火墙开关，不将失败回退到直接执行。

AppContainer 由普通用户创建。不同项目／权限范围使用不同主体；宿主通过继承的输入输出管道，与服务所属 AppContainer 内的小型 TCP 转发进程通信。宿主只绑定随机本地预览端口，不创建回环豁免、防火墙规则或管理员助手。网页使用运行卡片返回的实际 URL；内部监听端口与外部预览端口可以不同。

转发器使用 Windows 自带 .NET 编译器，在租约目录内准备一次；缺失仅影响沙箱网页预览，不影响普通聊天／直接执行。转发以原始字节传输，不能复用会截断输出的日志缓冲。随服务停止、应用退出或宿主崩溃清理，不自动恢复历史服务。启动取消也必须收回准备中的转发端口。

租约复用只根据真实项目路径、最终目录授权及网络模式判断；环境显示名称、探测记录、授权等待时间等不应造成新主体／重复授权。改变真实权限范围需要新的主体，不能扩大仍在运行的旧进程权限。

## 实验矩阵

所有程序、哨兵文件、报告和复制运行时位于 `.artifacts/tests/` 的独立目录。实验代码集中在 `tests/`。下列次数是实验样本量，不是产品限额。

| 实验 | 操作与观测 | 通过依据 |
| --- | --- | --- |
| 文件边界 | 项目读写、额外只读目录读取和拒写、额外可写目录、目录外哨兵、子进程继承、路径穿越／junction | 允许操作产生真实文件；拒绝操作不改哨兵；子进程仍受限 |
| 网络边界 | 无网络主体尝试访问本机监听器；启用网络主体运行本地 HTTP 服务并由宿主请求 | 阻断模式连接被拒；启用模式实际返回预期页面，非仅助手存活 |
| 稳定复用 | 连续命令、并发命令、跨会话同项目、两个项目、无关设置保存 | 正确输出／工作目录；非管理员宿主运行且禁止 UAC 启动入口；不同项目文件权限不串用 |
| 取消与超时 | 启动带子进程的长命令，分别取消／短超时，然后执行下一命令 | 父子进程退出，下一命令仍可执行；不吞掉故障或自动重试 |
| 终端与服务 | 复用已有真实 PowerShell／CMD／Node／Python 检查；多次 HTTP 启停 | 输出、文件与 HTTP 内容正确，停止后端口释放 |
| 转发完整性 | 超过日志上限的二进制 GET／POST、HTTP 升级后多轮双向通信、活动连接退出 | 内容字节一致，连接与转发 Job 均被清理；升级测试不冒充完整浏览器 WebSocket／HMR 验收 |
| 退出／崩溃恢复 | 正常关闭及隔离测试子宿主异常退出，再恢复其数据根 | 本次主体 ACL／进程清除，恢复不重放业务命令；不修改其他主体 |

## 证据与范围

记录操作数、失败、耗时、主体数、清理状态及报告路径。实验检查宿主不是管理员，并阻止产品加载用于 ShellExecute 的系统库；另核对源代码无 runas／回环授权启动路径。只检查本轮明确创建的主体，不修改其他系统条目。

先执行边界与复用检查，再运行本地预览／退出实验；全程不提权。发现问题只复测受影响场景，不扩大为全仓回归。未执行场景明确保留，不据短样本宣称长期零故障或完整攻击面评估。

当前范围不承诺自动改写应用硬编码端口、绝对重定向或跨端口 HMR 配置；使用实际转发 URL。HTTPS 证书行为、完整浏览器 WebSocket／HMR、Conda 全环境和外网代理组合需要分别验证，不能据本地 HTTP 成功推断。

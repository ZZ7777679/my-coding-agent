# MCP 常用服务与连接体验：首批实施

> 2026-09-22，用户授权先开发 MCP 模块的初步内容。扩展 M4 已有 MCP 服务，不增加插件运行时。

## 目标与范围

左侧 MCP 管理提供 Context7、GitHub 官方服务卡片，展示用途、账号要求、官方入口和添加操作。预设只填入可编辑配置；打开页面不联网、不自动登记或连接外部服务。保留本地 stdio、远程 HTTP 和现有浏览器配置。

- Context7：远程 `https://mcp.context7.com/mcp`，可先匿名尝试，支持 API Key 的 Bearer 认证。匿名配额、是否需要认证以服务实际响应为准。
- GitHub：远程 `https://api.githubcopilot.com/mcp/`，本批使用 PAT；提供仓库、Issue、PR、Actions 等工具组选择。认证不使用 OpenCode Go Key，不从其他应用读取账号凭据。
- 服务端点、认证方式、项目范围、超时均可编辑；预设不是端点白名单。服务身份稳定，编辑名称不另建条目，允许添加多个账号实例。
- 桌面使用表单配置，原始 JSON 引用留在高级选项。令牌可引用指定环境变量（进程优先、Windows 用户变量后备），或由 Python 在当前 Windows 用户下用 DPAPI 加密保存到应用数据根。读取目录只返回是否配置，不返回令牌、片段或摘要；令牌不进入普通配置、模型上下文或 Trace。
- 保存与连接分开，提供“保存并测试连接”；测试只执行握手与工具目录查询。普通调用继续按原有发现、预算、取消和失败语义执行，不自动重试。
- 错误区分凭据缺失、401、403、429、超时、网络连接和其他协议错误，给出可操作说明；不暴露服务异常原文、请求头或响应正文。
- 配置变化对新连接生效，界面显示已有连接是否仍使用旧配置，并提供重连；不在保存时打断正在调用的会话。
- 项目启用 / 停用复用现有关系，不在项目写入机器配置。服务摘要按当前项目进入模型，工具定义按需发现。

首批不包含 OAuth 登录、在线 MCP 市场、Langfuse / Sentry 等后续服务及插件打包；手动令牌方式在页面中明确说明，不以打开官方网页冒充已登录。2026-09-22 用户随后授权的 OAuth 增量另见 [OAuth 方案与操作](mcp-oauth.md)，不覆盖原 PAT 配置。

## 实施顺序与最小验证

1. 后端集中维护预设、认证引用和公开状态，扩展现有 DTO / RPC / schema / TypeScript；不新增依赖。
2. 左侧服务卡片、便捷配置、项目启用、连接错误和重连提示。
3. 隔离目录验证旧配置可读、加密凭据不泄露、HTTP 认证组装、失败分类、发现和调用；真实 Electron 完成添加 / 编辑 / 启用 / 连接流程。
4. 显式外网检查 Context7 握手及公开文档查询；GitHub 有明确配置的测试凭据时只读验收，否则记录未执行认证账户验收。网络测试不调用模型、不写远端仓库，不修改个人应用配置。

测试源码集中在 `tests/`，产物在 `.artifacts/tests/`。通过受影响检查后交付，不扩大无关回归。进度保存在 [M4](../progress/m4.md)。

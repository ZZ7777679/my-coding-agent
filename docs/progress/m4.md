### 2026-09-22：OAuth 首版交付与验证

**实现与行为**

- 复用已锁定 MCP SDK 的资源 / 授权服务器发现、动态登记、预登记 / 客户端元数据身份、授权码 / PKCE / state / issuer。没有新增依赖或部署中间授权服务。后端暂存登录，仅成功后保存；普通工具只用令牌，不因 401 自动开浏览器或重放。

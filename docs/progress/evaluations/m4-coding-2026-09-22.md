## P2：服务已停止仍提供“打开预览”，随后给出无关修复建议（实测缺陷）

**用户目标**：停止当前预览后，看清服务状态并知道如何再次查看页面。

**复现步骤**：让会话通过 `start_service` 启动本地页面；在聊天快捷区点击“停止程序”；等待状态变成“已停止”；点击仍然存在的“打开预览”。重启应用进入同一历史会话后也可复现。

**预期**：停止状态不再提供可用的预览按钮，或明确说明需要重新启动服务。**实际**：按钮仍可点，随后出现“操作未完成，请检查目录或重新打开应用。”本次目录、后端和会话均正常，原因只是服务已停止，检查目录或重启不能恢复服务。该问题不造成数据丢失，但会把普通用户引向错误的排查方向。

**证据**：首次主场景与重启只读复核各复现一次；[清晰截图](../../../.artifacts/tests/persona-coding-JMRufq/12-stopped-preview-confirmed.png) 与 `observations.json` 的 `stoppedPreviewButtonCount=1`、`stoppedPreviewResult` 一致。停止后真实 HTTP 已不再响应。

**源码定位**：`apps/desktop/src/renderer/src/ProgramCards.tsx:244` 的 compact 分支仅检查 `current.url`；同文件 `:302` 的完整卡片要求 `current.status === 'ready'`。`apps/desktop/src/main/index.ts:545` 拒绝非 ready 服务，`:140` 的通用边界把它转成上述目录 / 重启提示。

**最小建议**：快捷入口沿用完整卡片的 ready 条件；若状态在点击时变化，返回“服务已停止，请先重新启动”的具体提示。无需新审批、额外环境检测或自动重试。

## P3：成果列表按随机身份排序，寻找最新修改需要逐项打开（实测体验摩擦）

**用户目标**：完成一次修改后，快速找到最新结果，尤其是同一文件多次编辑时。

**复现步骤**：在同一会话依次创建 `src/main.py`、编辑 `src/main.py`、创建 `app.py`，然后打开“会话选项 → 查看修改成果”。

**预期**：列表顺序能反映时间或轮次，同文件重复项能区分。**实际**：本次显示“新建 src → 新建 app → 编辑 src”，既非时间正序也非倒序。按钮只有路径 / 操作 / 保存状态，必须打开后才看到时间与运行 ID。原 diff 内容正确，未发生成果丢失。入口本身也在输入区“···”菜单里，工具行唯一明显入口是 Trace。

**证据**：[窄窗成果截图](../../../.artifacts/tests/persona-coding-JMRufq/13-narrow-changes.png)、[保存记录顺序](../../../.artifacts/tests/persona-coding-JMRufq/changes-order.json)。`src/my_agent/changes/store.py:88` 附近以 `sorted(directory.glob('*.json'))` 排序，文件名是随机 change UUID；`apps/desktop/src/renderer/src/Changes.tsx:114` 附近按返回顺序呈现。

**最小建议**：按时间或运行轮次呈现成果，并在条目上给出简短时间 / 轮次。可考虑在文件工具摘要旁提供直接“差异”入口，保持 Trace 的详细记录用途。这里只给建议，未修改分页策略或协议。

## P3：Trace 在窄窗占据大部分对话区，日常排错的信息密度偏高（实测体验摩擦）

**用户目标**：对照正在看的回答与某次执行结果，同时决定下一步操作。

**复现步骤**：将原生窗口调到 960×650，点击 Trace；或点某个工具摘要展开详情。

**预期**：能快速看到动作、错误或产物，保留足够上下文。**实际**：Trace 在 736 CSS 像素宽的对话区覆盖 620 像素（约 84%），输入和大部分对话被挡住；需先关闭面板再继续。宽窗中详情默认显示完整 JSON，UUID、`completed` / `recorded` / `unfinished` 等内部文字先占据屏幕，差异入口位于正文之后。功能可用且没有越界或死锁，这是阅读与对照成本。

**证据**：[窄窗 Trace](../../../.artifacts/tests/persona-coding-JMRufq/09-narrow-trace-960.png)、[工具详情](../../../.artifacts/tests/persona-coding-JMRufq/06-filtered-trace.png)，`observations.json` 保存实际几何。`apps/desktop/src/renderer/src/style.css:2144` 在 1100px 断点将 Trace 改为绝对定位浮层；`Trace.tsx:219` 直接呈现状态，`:253` 直接显示详情 JSON。

**最小建议**：保留可关闭浮层，但先显示短动作 / 结果 / 错误与成果链接，把原始 JSON 保留为按需展开；若用户常在小窗口对照，可考虑可调宽度。该体验选择不应新增执行前置条件。

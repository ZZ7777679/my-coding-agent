## 当前事实与剩余事项

- M5 已有真实桌面、终端、Git、LSP、图片和 DeepSeek 联合验证。2026-10-19 官方 DeepSeek 合作示例以 14 次请求完成实现与独立静态 Review；未覆盖浏览器点击和 Goal 连续轮次，不能替代此前 Go 联合验收。
- 默认产品仍使用 OpenCode Go 双模型。已对齐独立 Chat / Messages / 模型目录路由并兼容旧配置；用户更换过期 key 后，双模型完整连接测试、各两请求的读取代码闭环及生产原生搜索均已通过。官方直连仍只是隔离演示入口。诊断中的旧失败保留，短样本不代表服务长期稳定。
- 合作空间已修正任务页多处折叠布局，补自动排布、方向连线和状态节点；群聊回答按原提问 / 目标关联，显示等待对象和活跃过滤。真实 Electron 在 1440 / 1000 宽度和重启恢复下通过。请求材料减量、后台压缩与扩展建议仍见 [开发影响分析](../research/release-update-2026-10/project-implications.md)，未进入本批。
- 左侧「工作流管理」已提供个人流程与 OpenSpec / Superpowers / Spec Kit 适配版，可查看来源、复制编辑，并在新建 / 已有任务中选择。阶段实际带入对应 Skill；定向 RPC / 材料检查与真实桌面创建、阶段保存、重启恢复通过。没有安装上游 CLI、修改默认个人流程或增加项目默认继承设置。
- 合作空间新增「工作视角」：模板阶段生成任务骨架，编辑范围 / 依赖 / 反馈，分配已有成员，按选定范围单次执行或持续推进。模型报告保留用户定义；节点阶段接入 Skill，原 Run / Goal 保留结果、失败、停止与接续记录。新增首会话接入入口，不自动新建会话。Python 定向 3 项、协议 151 项、真实 Electron 1 项通过；未验证真实模型的自主规划质量。
- 本轮补齐协作接纳反馈 / 只读接续、图拖动 / 连线 / 删除与分配保存、长输入和历史分页、同任务候选与来源、等待时长 / 精确取消 / 摘要；协议 v9。`report_work` 未知字段的误导提示已修正。Python 定向 13 项及补充兼容节点、协议 / 流合并 153 项通过；团队桌面通过，工作图最终三次连续复测通过。此前一次结果保存未落盘未稳定复现，不能据后续通过声称根因已修复。
- 保留限制：M5 GLM 长联合流程未通过、M4 程序终态保存偶发失败未定位根因、800K 长输入和个人 MCP OAuth 未实测。详见 [回顾第 4 节](project-status-and-roadmap-2026-10-19.md#4-已知待办与证据空白)。
- 当前 Git 工作分支为 `dev`，已 fetch 核实本地 HEAD 与 `origin/dev` 同为 `3d53f0b`（M4），没有远端分歧。正在整理 M5 提交并推送 `origin/dev`；本轮不合并 `main`。旧调研压缩包、解压资料和安装程序继续留在本地。
- 仍用 `StartAgent.cmd` 开发入口，数据按所选数据根持久化。安装包、自动更新与跨平台尚未交付；历史阶段编号不能直接当成新阶段任务。

## 下一步

根据 [DS 综合能力评价核对](../research/reports/harness-capability-ds-review-2026-10-19.md)，已实现用户限定的搜索与模型 Git 入口，以及项目级开关；没有扩展恢复工具、诊断汇总、项目凭据等其他模块。[R1–R4](../research/reports/m5-search-git-incremental-review-2026-10-19.md) 已修复：定向 Python 9 项、网关等待 / 退出与真实桌面验证通过。本轮先完成已授权的 M5 提交 / 推送与远端核对，再按用户反馈安排后续工作。

# M8 · 测试会话调研的可用性核对

日期：2026-10-22。依据：用户测试项目正式会话中的 DeepSeek 评价（事件 1328／1333／1362）、当前源码和本批定向验证。只读相关记录，没有把个人历史发送外部模型，也没有在仓库复制原会话。此表区分真实缺陷、已实现能力和新增建议；启动与打包按用户要求排除。验证明细见 [M8 进度](m8.md)。

| 评价方向 | 事实核对与本批处理 |
| --- | --- |
| 错误只有通用恢复提示 | 部分成立。补齐 worker 配置、模式、文件位置／匹配、Git、终端范围、下载及搜索的具体建议；未知错误仍保留原原因，不编造根因。没有宣称全部错误码均有专用处理。 |
| worker 关闭、Plan 不允许均显示参数错误 | 成立。分别返回 `WORKERS_DISABLED`／`TOOL_NOT_ALLOWED`；内部 worker 再委派为 `WORKER_CONTEXT_UNSUPPORTED`。保留原异常，尚未派发的可修正反馈交回模型，不结束整个 Run。 |
| 错误卡片缺恢复操作 | 部分旧结论。调查、接续、Trace、回退原来由会话调用处提供，不能仅看卡片组件得出“没有”。本批再接「设置与连接诊断」，错误码留在折叠详情。 |
| 搜索失败只有笼统说明 | 成立。保留实际模型、搜索次数、停止原因、块类型、服务错误码；无原生结果不自动归因于网络／额度。已知 URL 可用现有 `web_fetch`，不新增服务或默认重试。 |
| 多词发现查不到 worker | 当前已支持名称与多词匹配，已有定向用例通过。未重新增加完整目录常驻或另一套发现系统。 |
| 子任务开关隐藏／重启不保留 | 隐藏较深成立，增加入口旁快捷开启；真实存储重建验证开启及并发数保留，不支持“重启必定复位”的说法。开启不会自动创建任务。 |
| 子 Agent 内容挤在一起 | 用户反馈属实。改为独立卡片，折叠只有工作名，展开有目标范围、进度、输出和操作；旧记录从目标首行取名，刷新不复位折叠。 |
| 运行中无法追加、编码入口割裂 | 用户实测缺口成立。本批加入同 Run 追加和会话内工作台；文件可编辑、引用、准备 Agent 运行请求，所在目录可开 PowerShell／CMD。 |
| 缺独立测试工具所以不能验证代码 | 结论不成立。现有 `run_command`、终端及代码诊断支持实际执行；本批真实执行两个 shell。测试框架自动识别／聚合属于增强，不新增默认检查／失败自动修复流程。 |
| 预算默认过严 | 新配置累计不限已实现，旧用户设置保留，改进预算独立。没有强制改写旧预算或增设并行预检拒绝。 |
| 旧记忆仍说无法读取 token | 已只读确认一条启用的历史维护记录。当前用量工具存在，能力事实应来自实际工具；模型生成、未固定的 `capabilities` 条目不自动注入，记忆页显示原因，搜索／编辑／手动带入保留。未批量删除或改写用户数据。 |
| 上下文需逐项固定／排除、摘要主题索引 | 属于新增能力，现有请求材料清单、压缩切点与历史回读仍在。此次未增设另一套组装控制或强制覆盖率门槛，也不把折叠当上下文删除。 |
| 扫描截断没有说明 | 当前已有 `truncated`／`skipped` 事实；不重复添加另一套计数。用户可调整既有范围、分页及读取配置。 |
| 沙箱默认断网、配额／审批应更严格 | 与用户明确的兼容与免反复授权方向不符，本批不采纳。保留已选项目执行方式及真实边界说明。 |
| 协议版本散落、生成物不同步 | 版本选择确有重复；改由集中默认值生成 schema 路径、类型及前端校验入口，契约测试共用版本。未提交 v14 不是运行时协议不一致的证据；生成漂移检查通过。 |
| 外部编辑器、移动／重命名、历史难找 | 能力已存在；指南更新准确入口，集中到会话内「项目文件」。没有因此新增第二套编辑／历史服务。 |

## 保留的边界

- 本轮替身只决定模型响应；RPC、文件、持久化、Electron、ConPTY 均实际执行。没有通过重发个人会话验证线上模型，不据短样本宣称长期稳定。
- 未改变默认 direct、默认关闭子任务、有限预算快照、Goal 授权与真实调用故障停止规则；不加信任开关、逐工具审批、先填报告才能运行等门槛。
- 启动／打包、全库索引、AST 编辑、测试框架自动聚合及上下文交互扩展未实施。上述新增建议不能被列作已修复的缺陷，也不阻塞现有开发。
- 旧错误能力文字若早已在聊天原文中出现，仍属于历史；本次只停止自动记忆重复注入，不篡改历史或替模型断言所有旧知识无效。

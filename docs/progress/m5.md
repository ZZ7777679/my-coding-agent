## 已确认的接续约定

- 一个任务一个合作空间；输入项目目标可生成团队与有向图，用户编辑草稿后启动。
- 中心协调、分层、对等三种组织方式均在本阶段；节点是完整 Agent，复用既有运行核心。
- 成员身份独立于会话；群聊为主要入口，独立成员可并行，失败只停止受影响工作。
- 除合作空间外，内置编辑器 / 终端与 LSP / 图片等 Agent 能力均实现，不能再次缩减成轻量查看入口。
- 保留当前两个 OpenCode Go 模型，不增加视觉辅助模型；安装包和自动更新后置。
- Git 不需要远端或账号登录；阶段验收采用未配置 remote 的本地隔离仓库，不再建立测试远端。
- 默认原项目目录、无强制 Git / worktree / 信任开关；正常工作沿现有规则推进，测试与审批不成为额外执行门槛。

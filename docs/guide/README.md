## 一个简单完整的体验

1. 在「项目工作台」选择一个空目录。新建任务，阶段目标填“完成一个单页计数器”。
2. 打开首会话，选「常规 · 对话与执行」，发送：

   > 创建 index.html：一个 +1 按钮，点击后数字增加，localStorage 保存数字；写一份简短 README。不安装依赖。用当前项目已有 Python 启动本地预览，告诉我实际访问地址。

3. 在对话工具卡片查看写入和程序状态；到「编码工作台」看实际文件。打开返回的地址手动点按钮。
4. 如果已经安装并启用浏览器 MCP，再让 Agent 点击按钮、读取变化并保存截图。无需为了先写页面而配置 MCP。
5. 点工具动作的「Trace」看调用与结果。想重做某次请求时用「回退」预览影响。
6. 展开「复盘此会话」，写“看看本次有哪些重复工作，是否适合整理成项目规范或 Skill”，再点「开始复盘」。查看发现后自行选择是否生成、采用候选。

这是操作示例，真实生成与执行结果取决于模型、网络和本机环境；不会预先保证一次成功。团队 Review 的做法见第 07 篇。

## 几个贯穿应用的概念

| 概念 | 用途 |
| --- | --- |
| 项目 | 用户选择的真实目录；代码默认直接保存在这里 |
| 任务 | 阶段性长期目标、约束、流程、团队和工作图 |
| 会话 | 一条可独立接续的对话；可绑定任务和成员角色 |
| Run（一次运行） | 接纳一次请求后，模型与工具完成这一轮工作的过程；可能多次调用模型 |
| Goal | 在会话内围绕局部目标连续推进多个工作单元；不等于整个任务 |
| Trace | 对实际请求、工具和维护作业的过程查看入口 |
| 数据根 | 存放项目登记、会话、记忆、配置与日志；不是代码项目目录 |
